# Social GTM Copilot (Local Product Spine)

Local-first TypeScript scaffold for campaign and draft lifecycle management.

## Product rule
AI prepares. Buffer stages. Founder publishes. Analytics teaches.

## Included in Sprint 1
- Core domain schemas and enums
- Draft approval/rejection state transitions
- Placeholder weekly brief generation
- In-memory repository boundary
- Local CLI smoke command
- Vitest unit tests for safety and transitions

## Excluded in Sprint 1
- Buffer API integration
- LinkedIn/X/YouTube API integration
- Direct publishing
- Browser automation/scraping
- Credential storage

## Setup
```bash
npm install
npm run build
npm test
```

## Basic CLI
```bash
npm run cli
```
