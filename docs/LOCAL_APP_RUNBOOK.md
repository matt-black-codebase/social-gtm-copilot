# Local App Runbook

## Prerequisites
- Node.js 20+
- npm 10+

## Commands
```bash
npm install
npm run build
npm test
npm run cli
```

## Local workflow demo
1. Create campaign through service API.
2. Create drafts with channel + destination metadata.
3. Apply approval/rejection transitions.
4. Generate weekly brief placeholder.

## Notes
- Storage is in-memory for Sprint 1.
- No integrations with Buffer or social platforms.
