# Safety Boundaries

Hard bans in this repository:
- No direct platform publishing.
- No auto-comments.
- No auto-DMs.
- No auto-follow/connect.
- No scraping.
- No browser automation.
- No profile harvesting.
- No session cookies.
- No LinkedIn/X/YouTube credential storage.

Enforced product rule:
**AI prepares. Buffer stages. Founder publishes. Analytics teaches.**

## Domain guardrails
- Draft transitions are explicit and test-covered.
- Channel enum can classify records, but there are no platform API adapters in this sprint.
- Destination enum allows Buffer staging labels only; no outbound integration.
